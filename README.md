# Aspirian Student Platform

> **AI-powered learning, practice, assessment, and personalized education platform for Pakistani students.**

## Project Overview

Aspirian Student Platform is a standalone educational application designed to provide Pakistani students with a complete digital learning ecosystem.

The platform is being developed separately from the existing **Aspirian.pk WordPress website**.

### Existing Website

**https://aspirian.pk**

The existing WordPress website will continue to focus on:

* Educational articles
* Notes
* Study resources
* Free Online Tools
* Programming Tutorials
* SEO
* Organic traffic
* Downloads
* Job & Career Hub

* Public educational content
* Student discovery and acquisition

### New Student Platform

**https://app.aspirian.pk**

The new standalone application will focus on:

* Student accounts
* Personalized learning
* Question Bank
* MCQs
* Short Questions
* Long Questions
* Tests and examinations
* AI Tutor
* AI-powered learning assistance
* Personalized Revision
* Student analytics
* Vocabulary and grammar
* Writing practice
* Practical activities
* Coding
* Virtual labs
* Educational video and audio
* Teacher tools
* Parent features
* School-level features

# Vision

Our vision is to build **Pakistan's leading student-focused digital learning platform**.

Aspirian should become a place where students can:

> **Learn → Understand → Practice → Test → Analyze → Revise → Improve → Master**

The goal is not simply to provide notes or answers.

The platform should understand a student's learning needs and continuously help the student improve.

---

# Core Philosophy

Aspirian will follow these principles:

* Learning before memorization
* Understanding before answering
* Practice before examination
* Personalized learning
* High-quality educational content
* Verified and reviewed educational material
* Source-grounded AI

* AI as a learning assistant, not merely an answer generator

# Duplicate Prevention

Aspirian will have a multi-level duplicate detection system.

```text
New Question
      ↓
Exact Duplicate Check
      ↓
Similarity Detection
      ↓
Semantic Duplicate Detection
      ↓
Quality Validation
      ↓
Review
      ↓
Approved Question Bank
```

The system should identify both exact duplicates and substantially similar questions.

# Source-Grounded AI

Aspirian AI should prioritize content available in the approved Aspirian Knowledge Bank.

Example:

```text
Student Question
       ↓
Question Understanding
       ↓
Knowledge Bank Search
       ↓
Relevant Aspirian Content
       ↓
AI Explanation
       ↓
Answer
```

The AI should not present unsupported generated information as official Aspirian educational content.

The platform should distinguish where appropriate between:

* Aspirian Approved Content
* AI Explanation
* AI Suggested Practice
* External or Unverified Information

```text

    ↓
```

```text
    ↓
New Student Platform

Backend API
```

The Student Platform will **not** be placed inside the WordPress `/app/` directory.
